Location: Shenzhen, China
Reason: I visited china recently this summer and have planned out my own trip

Audience: First-timers, friends, family

Feel: I want the visitor to feel left out for not visiting and having a strong desire to visit the country

Design: Red and traditional chinese styling for the website, make it seem more modern and technical to match the energy china brings but also
showcase the difference between the technology and nature since China has both nature and large cities
Bring large attention to the viewer using expressive images and major attractions, slide show for showing major POIs, and use colors that are more modern
and reflect the traditional chinese styling

Main Window:
A large space for an image where this would be the first thing the user sees, text on the left side of the image showcasing the country "China, what to explore" as a title, a button that says "Explore Now".

The nav bar at the top should have the following:

- Home
- Top Attractions
- Food Guide
- Photo Gallery

Top Attractions:
A large space for an image where this would be the first thing the user sees, text in the middle that says "Top Attractions" and a sub paragraph giving a general description of what the web page is about. Have 4 sections each representing the top attractions all centered in the middle of the web page. Each section should have space for a title at the top left, an image below, and a sub paragraph below that. Use flex box for this implementation

Food Guide:
A large space for an image where this would be the first thing the user sees, text in the middle that says "Top Attractions" and a sub paragraph giving a general description of what the web page is about. Have 4 sections each representing a restaurant to eat in China where it is 2 on each layer. Have enough space for name of the restaurant in the center of the section, Address, and a sub description on what they serve as well as a button to the restaurant website. Use flex box for this implementation

Photo Gallery:
A large space for an image where this would be the first thing the user sees, text in the middle that says "Top Attractions" and a sub paragraph giving a general description of what the web page is about. Have 3 sections each representing a point of interest, 3 on each layer up to 6 in total of sections for each POI. Have space to hold a title in the top center, an image in the middle, and a sub description below in the image. Use flex box for this implementation

Mobile Support:
When the website is compacted on window size, the nav bar should be compacted down where there is a hamburger button on the top right and a search icon to the left of it. For the sections with the images, have one at each layer one by one, do not have multiple on each layer as the user should be able to scroll down for each sections like POIs, restaurants, for top attractions

Design Intent:
Additional information for the CSS design and website flow, should follow a modern and sleek design that represents the tech style of Shenzhen. Have minimal design choices and have most of the expressions come from the photos. Use the Montserrat font style. Use colors that would represent traditional chinese but also high tech. Colors like sapphire blue, black, white, pale gold, sparingly use Vibrant colors like Jade Green.

Breakpoints:
Phone: Nav bar collapsed to hamburger icon, One image box section at a time when scrolling down (No different experience)
Tablet: Nav bar collapsed to hamburger icon, Dynamic number of box sections a time with given space available
Desktop: Intended design
